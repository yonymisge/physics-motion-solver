# 🛠️ Uniformly Accelerated Motion Solver (SUVAT)

## 📌 Project Overview
I designed and coded this Python application during my **Grade 12 Natural Science studies in Ethiopia** to help optimize my physics exam preparations. 

The program bridges physical science concepts with software development principles by programmatically rearranging kinematic equations. It prompts the user for three known values out of the five core parameters of uniformly accelerated motion (SUVAT) and dynamically isolates the missing variables to output precise results.

## 🚀 Key Engineering Features
* **Constraint Handling:** Safely parses dynamic terminal inputs.
* **Equation Restructuring:** Evaluates conditional branches (`if-elif`) to select the correct algebraic equation form based on missing physical constraints.
* **Resource Optimization:** Designed as a zero-dependency, lightweight script runnable on low-bandwidth school infrastructures.
